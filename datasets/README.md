# Public test data

Large datasets are downloaded locally and are not committed to Git.

The first offline gate uses **Driving SLAM Test with Livox MID360**, created by
Kenji Koide and published on Zenodo as DOI `10.5281/zenodo.14841855` under
CC BY 4.0. The download script pins the archive byte size, SHA-256 and MD5.

Run:

```bash
./tools/download_public_mid360.sh
```
