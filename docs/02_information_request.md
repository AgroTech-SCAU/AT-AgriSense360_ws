# AgriSense-360 待确认信息清单

以下信息决定硬件架构和第一阶段开发，请按“已有 / 已采购未到 / 候选 / 不确定”标注，并尽量提供实物照片或原厂文件。

## 1. 项目边界

- 最终用途：科研原型、内部采集工具、比赛、课程、对外销售产品或项目交付？
- 第一优先级：数据采集、三维建图、彩色地图、厘米级全局定位，还是机器人导航？
- 目标机器人尺寸、速度、振动等级和供电范围；
- 典型连续工作时长、每天数据量和允许重量；
- 目标果园/农田面积、树行宽度、坡度、遮挡和网络覆盖；
- 精度指标：相对轨迹、绝对位置、地图重复度、彩色投影误差。

## 2. 已有实物

- Livox MID360S 的铭牌、序列号、固件版本、线束和转接头；
- CyperStereo MF287 的板卡/固件版本、USB 线和标定文件；已确认四路镜头为两个160°和两个200°；
- NUC 的品牌、完整型号、RAM、SSD 容量/型号、网口/USB 口和输入电压；当前仅确认候选CPU为Intel N100；
- 轮趣 G60/G70 的准确 SKU、主芯片、天线、协议手册和配套驱动；
- 是否有 RTK 基站、NTRIP 账号/SIM 卡和固定解测试记录；
- STM32 型号、原理图、PCB、固件源码和已有 IO 分配；
- 电源模块、外壳、支架、电池和机器人底盘是否已经采购。

## 3. 必须向供应商确认

### CyperStereo MF287

已确认：支持单路外部Trigger，2.8–3.3 V、最高30 Hz、0.5 ms高电平；设备内部FPGA使四路同步曝光；图像和IMU使用同一FPGA时间系统；图像时间戳为曝光结束时刻并提供曝光时长；整机通过一个USB3/UVC设备传输；Master提供曝光信号，Slave不提供。

仍需确认：

- Trigger连接针脚、输入保护要求和Master Exposure反馈针脚/电气定义；
- Trigger到曝光开始/结束的延迟及抖动；
- SDK是否输出硬件帧号/trigger counter，丢帧后四路序号如何处理；
- FPGA时间戳的单位、分辨率、回绕周期、复位行为和相对外部Trigger的漂移；
- ROS `header.stamp` 是否已换算到主机/UTC时间，还是保留FPGA时基；
- 四目出厂内外参和 Camera-IMU 外参格式；
- 30 fps 四路全开时的像素格式、实际 USB 带宽和推荐主机；
- SDK/固件版本对应关系及商用许可。

### GNSS

- 是否真的支持 RTK fixed，而非仅普通 GPS/北斗；
- 频点、通道数、原始观测量、RTCM3/NTRIP、更新率；
- 是否输出 1PPS，以及 PPS 对应哪一条时间报文；
- PPS 电平、边沿、精度和启动/失锁行为；
- 单天线还是双天线航向；
- ROS 2 输出 topic、消息类型、协方差和 fix 状态映射。

### Livox

- 取得MID360S对应版本手册、铭牌、序列号与固件信息；
- GPS 同步线束/针脚与所需 PPS、时间报文电平；
- 当前固件与 `livox_ros_driver2` 推荐版本；
- 是否采用 GPS 直连同步还是 NUC/PTP 网络同步。
